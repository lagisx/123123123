# BOX PRO

**BOX PRO** — настольное приложение для планирования и учёта тренировок по боксу. Приложение предоставляет инструменты для работы с программами тренировок, ведения дневника тренировок и контроля результатов.

## Возможности

### Программы тренировок

* просмотр доступных программ тренировок;
* просмотр информации о тренировках;
* разделение тренировок по уровню сложности;
* отображение количества раундов и их продолжительности;
* просмотр описания программы.

### Дневник тренировок

* добавление выполненных тренировок;
* сохранение даты и названия тренировки;
* указание количества выполненных раундов;
* добавление заметок;
* просмотр истории тренировок;
* удаление записей;
* просмотр статистики тренировочной активности.

### Таймер раундов

* запуск тренировочного таймера;
* настройка продолжительности раунда;
* управление раундами;
* отображение текущего состояния тренировки.

## Технологии

Проект разработан с использованием следующих технологий:

* **Java 21+** — основной язык программирования;
* **JavaFX 21** — создание графического интерфейса;
* **Apache Maven** — управление зависимостями и сборка проекта;
* **Supabase** — облачная платформа для хранения данных;
* **PostgreSQL** — система управления базой данных;
* **REST API** — взаимодействие приложения с серверной частью;
* **Gson** — обработка данных в формате JSON;
* **Git** — система контроля версий.

## Архитектура

Приложение построено по многослойному принципу с разделением ответственности между основными компонентами.

```text
src/
├── main/
│   ├── java/
│   │   └── ...
│   └── resources/
│       ├── fxml/
│       └── css/
└── test/
    └── ...
```

Основные компоненты приложения:

* **UI** — графический интерфейс и обработка действий пользователя;
* **Controller** — контроллеры JavaFX и обработка событий;
* **Model** — модели данных приложения;
* **Repository / DAO** — работа с хранилищем данных;
* **Service** — бизнес-логика приложения;
* **Supabase Client** — взаимодействие с REST API базы данных.
